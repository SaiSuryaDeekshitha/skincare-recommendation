# Skincare Product Recommendation using Data Science

Week 1 project of the Data Science with Python Analyst Internship (YuvaIntern).

## Problem
Online skincare shoppers get generic recommendations. This project explores how skin type, product attributes and review text can be used to recommend products customers are likely to rate highly.

## Planned Approach
1. Data cleaning (pandas)
2. Exploratory data analysis
3. Sentiment and topic analysis of reviews
4. Hypothesis testing
5. Recommenders: popularity baseline, content-based, collaborative, hybrid
6. Evaluation: RMSE, Precision@K, NDCG

## Dataset
Sephora Products and Skincare Reviews (Kaggle, public).

## Tools
Python, pandas, NumPy, matplotlib, seaborn, scikit-learn, NLTK/VADER, SciPy

## Status
Week 1: problem definition and plan (see report). Next: data exploration.
